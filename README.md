# NJU Agent

南京大学软件学院预推免考核项目：从零实现一个能够读写文件、执行命令并与大语言模型协作完成编程任务的智能体。

Git 仓库地址：<https://github.com/nobody1111725/nju_agent>

当前版本为 `0.6.0`，已完成第五阶段的上下文管理与特色功能，默认最多执行 20 轮模型请求，并增加了重复调用提醒、实时工具状态显示和可恢复会话记录，具备：

- Python CLI 入口：`nju-agent`；
- 从环境变量加载运行配置；
- 工作区路径校验；
- OpenAI 兼容接口模型客户端（默认 DeepSeek）；
- `list_files`、`read_file`、`write_file`、`edit_file` 和 `run_command` 本地工具；
- 文件路径限制在配置的工作区内；
- 命令超时和工具输出长度限制；
- `.env` 自动加载，且不会覆盖已有环境变量；
- 危险命令拦截、模型响应校验和重复工具失败熔断；
- 工作区内的运行日志，不记录 API Key；
- 上下文字符预算和旧工具交互压缩；
- `update_plan` 任务计划工具，支持步骤、当前进度和完成状态；
- CLI 实时显示工具名称、命令参数和执行状态，并使用终端旋转指示器表示运行中；
- Web 界面通过 SSE 实时推送具体工具指令、参数和状态，并将记录归属于对应对话轮次；
- 文件工具状态会显示具体路径、行范围或字符数量，便于观察 Agent 的实际操作；
- 会话自动保存到工作区的 `.nju-agent-sessions.json`，完整保留聊天记录，可使用 `/sessions` 查看、`/resume [会话ID]` 恢复、`/new` 新建会话；
- 模型决定调用工具、工具执行、结果回传模型的闭环；
- 最大循环步数和模型、工具错误处理。

## 运行

需要 Python 3.10 或更高版本。开发模式下可直接运行：

```text
python -m nju_agent.cli
```

也可以安装当前项目后使用命令：

```text
python -m pip install -e .
nju-agent
```

## 浏览器界面

启动本地前端界面：

```text
python -m nju_agent.cli --web
```

然后在浏览器访问 `http://127.0.0.1:8765`。页面可新建、恢复或删除会话、查看完整聊天记录，并实时显示文件读取、写入、编辑和命令执行的具体参数与状态；Agent 修改已有文件时会直接原地改写源文件，不会生成副本。工具记录下方会显示类似 GitHub 的统一差异视图，绿色表示新增行，红色表示删除行；该差异只用于页面展示，不会生成额外文件。Agent 回复支持标题、列表、表格、代码块、行内代码、粗体和安全链接等 Markdown 格式。Web 服务只监听本机地址，继续使用现有本地工具和工作区会话文件。

模型完整回答到达后，正文会以带闪烁光标的打字机效果逐字显示。该效果是前端对完整回答的渐进展示，不是模型接口本身的 token 级流式响应。

每轮对话完成后，页面会将该轮的文件读取、编辑和命令执行记录显示在对应 Agent 回复下方，并保存为可展开的“运行指令”分组。可随时收起或展开任意前序轮次；展开状态会保存在当前浏览器中，重新打开页面或恢复同一会话后仍会保留。运行记录和文件差异随会话保存至 `.nju-agent-sessions.json`。

输入框左下角的回形针可添加代码或文本附件，也可以直接把文件拖入输入框上传。支持 `.c`、`.cpp`、`.h`、`.hpp`、`.py`、`.json`、`.csv`、`.md` 等常用格式，以及 JavaScript、TypeScript、Java、Go、Rust、HTML/CSS、YAML、SQL、Shell、`Makefile` 和 `Dockerfile`。每轮最多 10 个附件、每个不超过 2 MB，且必须是 UTF-8 文本；附件保存在工作区的 `.nju-agent-attachments/` 下，任务执行时 Agent 会获知路径并按需用本地 `read_file` 工具读取。待发送的附件标签可点 `×` 取消上传，服务端会删除对应临时文件；已发送附件的名称和大小会显示在该轮用户消息下方，恢复历史会话后仍可查看。该目录外的路径、二进制文件和未允许格式会被拒绝。

恢复或完成会话后，侧栏“已修改文件”会按路径汇总该会话的所有文件改动。点击文件可在浏览器新标签查看当前内容；服务端只允许打开该会话实际产生文件差异的工作区 UTF-8 文本文件。

项目根目录的 `.env` 需要设置 `NJU_AGENT_API_KEY`、`NJU_AGENT_MODEL=deepseek-v4-pro`、`NJU_AGENT_BASE_URL=https://api.deepseek.com/v1` 和 `NJU_AGENT_WORKSPACE=.`。默认配置面向 DeepSeek 的 OpenAI 兼容接口，也可替换为兼容同一接口的模型。`.env` 和运行日志均已忽略，不会被提交；API Key 不能写入 README 或 Git 仓库。

会话在每次任务完成后自动保存到工作区的 `.nju-agent-sessions.json`。CLI 可使用 `/sessions` 查看、`/resume <会话ID>` 恢复、`/new` 新建会话，也可启动时使用 `python -m nju_agent.cli --resume <会话ID>`。上下文压缩只影响发送给模型的临时请求副本，不会删除本地保存的完整聊天记录。
